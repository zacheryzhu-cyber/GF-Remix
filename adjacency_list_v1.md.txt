# Semiconductor Fab Utilities — Adjacency List v1

## Purpose

Representative semiconductor-fab Facilities utility dependency graph
for AI-agent / Neo4j knowledge-graph demonstrations.

Scope:
- UPW (Ultrapure Water)
- CHW (Chilled Water)
- Small electrical/control dependency layer
- Representative semiconductor process loads

IMPORTANT:
This is a representative engineering/demo topology.
It is NOT claimed to be the actual STMicroelectronics Singapore topology.
All quantities, redundancy arrangements and process-tool utility assignments
must be validated with the customer's Facilities engineers before being
presented as site-specific information.

---

# 1. Graph conventions

Each line follows:

SOURCE_ID -> RELATIONSHIP -> TARGET_ID

Primary relationship semantics:

SUPPLIES
FEEDS
DISTRIBUTES_TO
RETURNS_TO
COOLS
POWERS
CONTROLS
BACKUP_FOR

Direction generally follows physical/functional dependency.

Example:

UPW-P-01 -> SUPPLIES -> UPW-HDR-01 [max_capacity: 500, current_load: 420, unit: GPM]

means:

UPW-P-01 supplies UPW-HDR-01.

# 9. IMPORTANT GRAPH INTERPRETATION RULES

## 9.1 Redundancy

A backup relationship does NOT automatically mean the backup is
currently carrying flow.

It means the asset represents a potential alternate/standby capability.

Failure analysis must consider whether an alternate operational path exists.

---

## 9.2 Cross-connects

Relationships such as:

UPW-LOOP-A -> FEEDS -> UPW-LOOP-B [max_capacity: 500, current_load: 420, unit: GPM]

represent possible alternate routing.

They should not automatically be interpreted as simultaneous normal flow.

---

## 9.3 Return paths

Return relationships create intentional graph cycles.

For example:

UPW-TK-03
→ UPW-P-03
→ UPW-HDR-01
→ UPW-LOOP-A
→ UPW-TK-03

This is an intentional utility circulation loop.

---

# 10. FAILURE ANALYSIS USE CASES

The AI agent should be able to reason about the graph.

## Scenario A — Single pump failure

Input:

"UPW-P-01 fails."

Agent should determine:

- UPW-P-02 is an alternate feed pump.
- UPW generation may remain available.
- Determine whether downstream UPW supply paths remain connected.
- Identify process tools that could ultimately be affected.

Do NOT automatically conclude that every downstream tool fails.

---

## Scenario B — Dual pump failure

Input:

"UPW-P-01 and UPW-P-02 both fail."

Agent should determine:

- Raw-water feed capability is lost.
- No alternate feed pump remains.
- Upstream UPW generation is impaired.
- Determine downstream impact based on remaining stored UPW and circulation capability.

---

## Scenario C — Chiller failure

Input:

"CHW-CH-01 fails."

Agent should:

1. Find downstream dependencies.
2. Check common CHW header connectivity.
3. Identify alternate chillers.
4. Determine whether available cooling capacity remains.
5. Identify process loads with CHW dependency.
6. Identify loads with alternate cooling paths.

---

## Scenario D — MCC failure

Input:

"MCC-01 fails."

Agent should identify:

MCC-01
→ UPW-P-01
→ UPW system

MCC-01
→ UPW-P-04
→ UPW system

MCC-01
→ CHW-P-05
→ CHW system

# 12. AGENT REASONING REQUIREMENTS

The AI agent should distinguish:

### Direct dependency

A directly connected relationship.

Example:

CHW-HX-01 -> COOLS -> TOOL-CMP-01 [max_capacity: 1200, current_load: 850, unit: Tons]

### Indirect dependency

A dependency several hops upstream.

Example:

TOOL-CMP-01
→ CHW-HX-01
→ CHW-ZONE-A
→ CHW-HDR-01
→ CHW-P-05
→ CHW-CH-01

### Alternate dependency

A second valid route to the same required utility.

### Shared dependency

Multiple process tools ultimately depend on the same upstream asset.

### Single point of failure

An asset for which no viable alternate path exists.

### Redundant asset

An asset with an alternate asset/path capable of maintaining service.
